# PassEVA

Plateforme indépendante de préparation au test EVA.

Ce dossier contient le site statique prêt à être publié avec GitHub Pages.

## Publication GitHub Pages

1. Créer un dépôt GitHub appelé `testEva`.
2. Envoyer tous les fichiers de ce dossier dans le dépôt.
3. Activer GitHub Pages depuis la branche `main`, dossier `/root`.

Le site principal est `index.html`.
